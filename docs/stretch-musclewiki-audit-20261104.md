## Exact-match near misses (do not add)

- `trad_nalen`: `thread-the-needle-hip-over-knees` changes leg placement to a pigeon-like hip position, unlike DRIV's standard all-fours arm-threading.
- `latsstretch_bank`: `lat-and-shoulder-external-rotation-stretch-3-kneeling-dowel` requires a dowel and palms-up external rotation; DRIV has no dowel.
- `liggande_hamstring`: `hamstring-stretch-supine-static` requires a strap and instructs a dynamic end-range tug; DRIV also allows hand-on-calf static hold.
- `arm_over_brost`: `shoulders-stretch-variation-four` adds torso rotation and elbow/forearm technique absent from DRIV cues.
